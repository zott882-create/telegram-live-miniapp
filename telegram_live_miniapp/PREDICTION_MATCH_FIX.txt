ИСПРАВЛЕНИЕ ОТКРЫТИЯ МАТЧА ИЗ ПРОГНОЗОВ

1. Синтетический Scores24 fixture_id больше никогда не используется как ID API-Football.
2. Матч открывается только при наличии api_football_fixture_id.
3. Открывается точная fixture_item выбранного прогноза, без поиска по общей карте матчей.
4. Статистика при открытии из прогнозов читается из сохранённого снимка PostgreSQL.
5. События и статистика с ID других команд отбрасываются.
6. Если события выбранного матча не сохранены, чужая хронология не показывается.
7. Старые и новые связи Scores24 -> API-Football проходят более строгую проверку команд.
