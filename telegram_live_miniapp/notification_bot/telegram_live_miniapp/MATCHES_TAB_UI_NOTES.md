# V9.97 — обновление вкладки «Матчи»

- Добавлены логотипы обеих команд в переключатель команд.
- Добавлены логотипы обеих команд во все строки последних матчей.
- Логотипы берутся из существующего защищённого кэша; если логотипа нет, показываются инициалы.
- Карточки матчей, блок показателей, даты, результаты и отступы переработаны для более современного вида.
- Сохранена адаптация под узкие экраны Telegram Mini App.
