Исправление исчезновения матчей:
- кнопка «Уведомления» открывает только фильтры уведомлений;
- кнопка «Фильтр» снова управляет фильтром главной ленты;
- пустой/ошибочный ответ LIVE API больше не стирает последний рабочий список;
- при пустом ответе выполняется один принудительный повторный запрос;
- последний рабочий список хранится локально до 5 минут.
