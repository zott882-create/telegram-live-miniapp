PREDICTION 5-MINUTE REFRESH
===========================

Changed:
- Background prediction worker now checks today's fixtures every 5 minutes by default.
- The same fixture-list request updates scores, detects finished forecast matches,
  and immediately recalculates hit rate, return, profit and ROI.
- Newly discovered fixtures are checked for a model prediction immediately.
- Accepted forecasts retain their original pre-match probability and minimum odd.
- Already accepted forecasts never request predictions/odds again; only scores change.
- Fixtures without prediction/odds use an exponential retry backoff to protect the API quota.
- Manual refresh uses the incremental scanner instead of rebuilding all fixtures.
- The open Predictions page refreshes itself every 5 minutes.
- UI text now says that forecasts and scores are checked every 5 minutes.

Default environment settings:
PREDICTION_LIVE_REFRESH_SECONDS=300
PREDICTION_NO_DATA_RECHECK_SECONDS=1800
PREDICTION_WEAK_MODEL_RECHECK_SECONDS=10800
PREDICTION_ODDS_RECHECK_SECONDS=1800
PREDICTION_SCAN_MAX_FIXTURES_PER_CYCLE=400

The frozen notification bot source was not modified.
