LIVE ZOT — PostgreSQL is required
=================================

Railway:
1. Open the project and click New -> Database -> PostgreSQL.
2. In the bot service Variables, add a reference to PostgreSQL variable DATABASE_URL.
3. Keep NOTIFY_STORAGE=postgres (the application also enforces it automatically).
4. Deploy again.

Startup behavior:
- Without DATABASE_URL the bot intentionally does not start.
- If PostgreSQL is unavailable during startup, the bot intentionally does not start.
- SQLite fallback for predictions and notification state is disabled.
- Redis is mandatory in this build and is used for cache plus the distributed background-worker lock.

Unified table:
- livezot_prediction_days
- livezot_service_state
- Primary key: (source, stat_date)
- JSON data is stored as PostgreSQL JSONB.
- Old PostgreSQL tables from earlier bot versions are migrated automatically and removed.
