# V10.4 — быстрые и чистые прематчи

Исправлены три причины медленной/неполной ленты прематчей:

1. `build_payload()` больше не отправляет SportScore ID (`ss:*`) в IGScore для
   массовой проверки live-коэффициентов. У SportScore уже есть собственные
   prematch odds, а лишняя проверка создавала сотни бесполезных запросов.
2. Страницы сегодня/завтра/следующий день загружаются параллельно. Таймаут
   SportScore снижен с 20 до 8 секунд, календарный кеш увеличен до 5 минут.
3. LIVE и завершённые матчи отсекаются на трёх уровнях: HTML-секция SportScore,
   серверный `/api/prematch` и интерфейс Mini App. Матч исчезает из прематча
   сразу после начала, даже если в кеше остался старый снимок.

Дополнительно:

- widget API с лимитом 50 теперь используется только как аварийный fallback;
- обычный календарь больше не смешивается с live/recent из widget API;
- добавлен single-flight, чтобы несколько пользователей не запускали несколько
  полных загрузок одновременно;
- `source_stats` показывает время загрузки, число отброшенных строк и частичные
  страницы;
- добавлены тесты на параллельную загрузку и разделение scheduled/live/finished.
