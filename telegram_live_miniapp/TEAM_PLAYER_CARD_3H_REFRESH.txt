КАРТОЧКИ КОМАНД И ИГРОКОВ: ОБНОВЛЕНИЕ ПО ЗАХОДУ РАЗ В 3 ЧАСА

1. Фоновых запросов API-Football нет.
2. Карточка команды и карточка игрока читаются из общего PostgreSQL-кэша.
3. Пока снимку меньше 3 часов, все пользователи получают сохранённую информацию без API-запросов.
4. Первый пользователь, открывший карточку после истечения 3 часов, один раз обновляет её через API-Football.
5. Одновременные открытия защищены общей блокировкой: один источник обновляет данные, остальные получают тот же снимок.
6. Новый снимок снова используется всеми пользователями следующие 3 часа.
7. Переменная Railway TEAM_PLAYER_CARD_REFRESH_SECONDS позволяет изменить интервал; значение по умолчанию 10800 секунд.
8. Сокращение старого TTL применяется сразу: записи, ранее сохранённые на 12/24 часа, теперь оцениваются по текущему лимиту 3 часа.
