LIVE → API-FOOTBALL CARD ON CLICK
=================================

What changed
------------
- The LIVE list and its score/minute remain sourced from IGScore.
- Clicking a LIVE match now resolves the same fixture in API-Football.
- The normal match card opens with API-Football team IDs, league data, lineups,
  events, statistics and club navigation.
- IGScore score/minute are overlaid on the API-Football fixture so the LIVE
  header stays current even when API-Football is slightly delayed.
- The mapping is stored in PostgreSQL and Redis by IGScore match ID, so other
  users reuse the same result instead of searching again.
- If API-Football does not cover the match or matching is ambiguous, the old
  IGScore LIVE detail opens as a safe fallback. A random fixture is never used.

Safety
------
- IGScore match ID and API-Football fixture ID are kept separate.
- Matching checks both teams, order, competition, score and team variant
  (senior / women / U19-U23 / reserves).
- The frozen notification_bot files were not changed.
