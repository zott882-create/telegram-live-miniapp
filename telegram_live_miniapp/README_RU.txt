telegram_live_miniapp COMBINED V1
===================

В ОДНОМ ПРОЕКТЕ:
1) / — новый раздел «Матчи» через API-Football:
   - LIVE и прематч;
   - счёт, минута и статус;
   - статистика, события, составы и H2H по открытию вкладки;
   - тренды рассчитываются по последним матчам команд;
   - Redis-кэш и защита лимита 5 запросов/сек.

2) /notify/ — полностью готовый бот уведомлений V10_03.
   Исходные файлы в notification_bot/telegram_live_miniapp не менялись.

БЕЗОПАСНОСТЬ КЛЮЧА
------------------
API-ключ НЕ записан в ZIP и НЕ попадает в браузер. На Railway добавьте Variable:

API_FOOTBALL_KEY = ваш ключ

НАСТРОЙКА RAILWAY
-----------------
В Variables сохраните существующие переменные готового бота:
BOT_TOKEN
BOT_USERNAME
MINIAPP_SHORT_NAME
ADMIN_IDS
DATABASE_URL
REDIS_URL

Добавьте:
API_FOOTBALL_KEY
APP_TIMEZONE=Europe/Moscow
API_FOOTBALL_MAX_RPS=4
API_FOOTBALL_TODAY_TTL=60
API_FOOTBALL_OTHER_DATE_TTL=1800

После деплоя главная ссылка Railway открывает «Матчи».
Кнопка «Уведомления» открывает готовый бот в исходном виде.

КАК ЭКОНОМЯТСЯ 7 500 ЗАПРОСОВ
-----------------------------
- список матчей текущего дня: общий запрос примерно раз в 60 секунд;
- другие даты: кэш 30 минут;
- статистика: только при открытии вкладки «Статистика»;
- события: только при открытии вкладки «События»;
- составы: только при открытии вкладки «Составы»;
- H2H и тренды: только при открытии соответствующей вкладки;
- одинаковые запросы всех пользователей объединяются и берутся из Redis.

ЛОКАЛЬНЫЙ ЗАПУСК WINDOWS
------------------------
1. Дважды нажмите START_LOCAL_WINDOWS.bat
2. Введите API-Football key в окне.
3. Откройте http://127.0.0.1:8080

Для просмотра без API используйте START_DEMO_WINDOWS.bat.

ВАЖНО
-----
API-Football key проверяется только при реальном запросе к API. Если данные не
загружаются, откройте Railway Logs и проверьте переменную API_FOOTBALL_KEY.
