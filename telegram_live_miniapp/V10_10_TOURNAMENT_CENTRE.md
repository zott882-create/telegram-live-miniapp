# V10.10 — Внутренний центр турнира

## Добавлено

- Внутренняя страница турнира без переходов на SportScore.
- Открытие турнира из заголовка лиги в прематче, из карточки матча и из карточки команды.
- Вкладки: обзор, матчи, таблица, игроки, статистика, команды, плей-офф.
- Календарь и результаты с фильтрами: все, предстоящие, завершённые, live.
- Выбор тура с отдельной загрузкой выбранного тура для высокой скорости.
- Переключение сезонов, если источник предоставляет список сезонов.
- Общая и групповая таблица, форма команд.
- Лучшие бомбардиры, ассистенты и игроки по рейтингу, когда эти данные доступны.
- Статистика турнира и команд.
- Список участников с переходом во внутреннюю карточку команды.
- Сетка плей-офф и история чемпионов, если турнир содержит эти разделы.
- Переход на любого соперника из списка матчей команды.
- История внутренней навигации между командами и возврат назад.
- Точное открытие матчей из других туров по уникальному ID события.

## Безопасность и навигация

- В интерфейсе нет внешних ссылок SportScore.
- Внешние URL провайдера удаляются сервером из данных страниц команд и турниров.
- Разрешены только валидированные внутренние пути турниров и идентификаторы команд.

## Проверка

- 15 автоматических тестов пройдено.
- Python-компиляция: OK.
- JavaScript-синтаксис: OK.
- ZIP-архив проверен на целостность.

## Примечание

В некоторых небольших турнирах источник может не публиковать ассисты, рейтинги игроков, сетку плей-офф или историю чемпионов. В таком случае соответствующая вкладка показывает внутреннее сообщение «данные пока недоступны» и не перенаправляет пользователя на сайт.
